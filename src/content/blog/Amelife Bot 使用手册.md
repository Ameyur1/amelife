# Amelife Bot 使用手册

这份手册用于日常开机、订阅和排查推送。机器人运行在这台电脑上：**电脑关机，或机器人与 NapCat 没有同时运行时，不会检查新内容。**

## 每次开机后启动

1. 双击 `C:\Users\Ameyuri\Desktop\Amelife\bot\start.bat`，保持弹出的机器人命令窗口打开。
2. 双击 `C:\Users\Ameyuri\Desktop\Amelife\bot\NapCat.Shell\launcher-user.bat`，确认机器人 QQ 小号登录成功，保持 NapCat 窗口打开。
3. 用另一个 QQ 号给机器人发 `/ping`。收到 `pong · Amelife Bot 已连接`，说明 QQ 收发链路已接通。

已经安装好的环境不需要每次运行 `install.bat`，也不需要重新填 Token。若 NapCat 要求扫码或手机确认，请完成登录。只打开其中一个窗口，机器人不能正常推送。

停止时，在 `start.bat` 的命令窗口按 **Ctrl+C**，再正常关闭 NapCat。若是在 PyCharm 里运行 `bot.py`，点击 Run 窗口的红色停止按钮。

## 在 QQ 里使用

所有指令都以 `/` 开头，发在希望接收推送的那个私聊或群里。私聊与每个群的订阅互相独立。

| 指令 | 用途 |
| --- | --- |
| `/帮助` | 查看机器人内置指令 |
| `/ping` | 测试机器人是否在线 |
| `/订阅列表` | 查看当前聊天的订阅和对应 ID |
| `/检查更新` | 立即检查当前聊天的订阅 |
| `/状态` | 查看连接数、订阅数和检查间隔 |
| `/测试推送` | 发送一条测试消息 |
| `/取消订阅 ID` | 取消指定订阅；先用 `/订阅列表` 查 ID |

群里只有群主、群管理员或机器人超级用户能新增、取消订阅和测试推送。修改或检查指令发得太快时，先等约 2 秒再试；同一个聊天的 `/检查更新` 最多每分钟一次。

## 订阅自己的网站

在要接收通知的 QQ 私聊或群里发送：

```text
/订阅 rss https://amelife.pages.dev/rss.xml
```

收到“已添加订阅”后，等约 2 秒，发送 `/检查更新`。**第一次成功检查只记录网站已有文章，不会把旧文章推送一遍。** 以后发布新文章，要等网站部署完成、新文章已经出现在 `https://amelife.pages.dev/rss.xml`，机器人下一次检查时才会发现它。也可以手动发 `/检查更新`。

默认每 10 分钟自动检查一次。网页上能看到新文章，不代表 RSS 已经更新；遇到“文章发了但没有推送”，先在浏览器打开上面的 `rss.xml`，查新文章标题和链接是否在里面。

## 订阅 B 站 UP 主

把下面的示例 UID 换成要关注的 UP 主 UID：

```text
/订阅 bilibili 2267573
```

这条指令会分别创建“视频”和“动态”两个订阅，所以 `/订阅列表` 里会出现两个 ID。首次成功检查同样只建立基线。B 站内容通过 RSSHub 获取；公共实例可能超时或暂时返回错误，视频和动态也可能只有其中一个抓取成功。此时看 `/检查更新` 的错误提示，不要把“抓取失败”当成“没有更新”。

## 取消订阅

先发送 `/订阅列表`，找到要取消的数字 ID，再发送，例如：

```text
/取消订阅 2
```

这只会取消当前私聊或当前群里的那条订阅，不会影响其他聊天。

## 收不到推送时这样检查

1. 发 `/ping`。没有回复时，检查 `start.bat` 和 NapCat 两个窗口是否仍在运行、机器人小号是否登录。NapCat 应启用 **WebSocket 客户端**，连接到 `ws://127.0.0.1:8080/onebot/v11/`。
2. 发 `/订阅列表`，确认订阅加在了正确的私聊或群里。
3. 若是刚订阅，发一次 `/检查更新` 建立基线；这次推送 0 条是正常的。之后有新内容才会推送。
4. 网站文章未推送时，先检查 `https://amelife.pages.dev/rss.xml` 是否已经出现该文章的新链接，再等下一轮检查或手动 `/检查更新`。只修改旧文章且 RSS 条目 ID 或链接不变，通常不会当作新文章。
5. `/检查更新` 显示超时、HTTP 503 等错误时，说明该来源这次抓取失败，不代表没有新文章。详细错误可查看 `C:\Users\Ameyuri\Desktop\Amelife\bot\logs\bot.log`。

电脑关闭期间不会实时推送。重新开机后，机器人只能补查来源当前仍保留的最近条目。

## Token 和安全

NapCat 网页登录密钥与项目 `.env` 中的 `ONEBOT_ACCESS_TOKEN` **不是同一个东西**。前者登录 NapCat 管理页面；后者必须与 NapCat **WebSocket 客户端**里的 Token 一致。正常开机无需重新填写。不要把 `.env`、Token、QQ 登录态或未遮挡的配置截图发给别人。

需要重新安装、修改配置或调试时，查看项目里的 `README.md` 和 `PyCharm使用指南.md`。
